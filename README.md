# Bagdala Travel

Modern WordPress theme for a tourist agency — built with Sage 11, Tailwind v4, and Vite.

## Performance — 100/100

![Mobile](docs/images/mobile-100.png)
![Desktop](docs/images/desktop-100.png)

[Live PageSpeed report](https://pagespeed.web.dev/analysis/https-bagdalatravel-rs/h79tr8nnxt?form_factor=desktop)

## Features

- Custom booking system (AJAX modal, email notifications, seat management)
- Optimized for Core Web Vitals — LCP 1.7s mobile
- Responsive design with Tailwind CSS
- Clean, modular architecture

## Tech Stack

- WordPress + Sage 11
- Laravel Blade
- Tailwind CSS v4
- Vite
- Secure Custom Fields (SCF)

## Setup

\`\`\`bash
composer install
npm install
npm run build
\`\`\`

Copy `.env.example` to `.env` and update `WP_HOME` and `WP_SITEURL`.
